Укажите личный API-токен (обязателен для запросов). Получить его можно в Telegram-боте @poiskkinodev_bot (сервис poiskkino.dev).
Даты входят в карточку фильма, поэтому дополнительные запросы к API не нужны. Если российской даты нет, берётся мировая; если нет никакой даты, дата выхода остаётся пустой (год выпуска записывается в любом случае).
Дата и место рождения актёров и съёмочной группы. Один запрос к API на каждого человека, поэтому при бесплатном токене (200 запросов в сутки) включать не рекомендуется. Фотографии персон загружаются и без этого.
