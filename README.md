# КиноПоиск Next — плагин метаданных для Jellyfin 12.4

Плагин добавляет **КиноПоиск** в качестве источника метаданных для фильмов и сериалов в Jellyfin. Он использует [poiskkino.dev API](https://poiskkino.dev/) для получения информации о произведениях и персоналиях.

> Это отдельный форк, предназначенный для **Jellyfin 12.4**. Он не является официальным плагином Jellyfin или официальным продуктом КиноПоиска.

## Совместимость

- **Jellyfin Server:** 12.4.x (целевой ABI: 12.4.0.0). Плагин собирается против пакетов Jellyfin 12.4.0 и проверяется на этой версии сервера.
- **.NET:** 10.
- Версия плагина начинается с версии Jellyfin, для которой он собран: 12.4.x.y.
- Серверам Jellyfin 12.0–12.3 каталог по-прежнему предлагает последнюю сборку предыдущей линии (12.1.0.x); она больше не развивается.
- Сборки для Jellyfin 10.x этим форком не поддерживаются.

## Установка

### Через каталог плагинов (рекомендуется)

1. Откройте **Панель управления → Плагины → Репозитории**.
2. Добавьте репозиторий со следующим URL манифеста:

   ```
   https://raw.githubusercontent.com/Rev01T/jellyfin-plugin-kinopoisk-next/master/dist/manifest.json
   ```

3. Сохраните репозиторий и перейдите в **Плагины → Каталог**.
4. Найдите **КиноПоиск** и установите плагин.
5. Перезапустите Jellyfin, если сервер запросит это после установки.

### Ручная установка

1. Откройте раздел [Releases](https://github.com/Rev01T/jellyfin-plugin-kinopoisk-next/releases).
2. Скачайте ZIP-архив последнего релиза для Jellyfin 12.
3. Установите плагин способом, предусмотренным вашей установкой Jellyfin, и перезапустите сервер.

Не устанавливайте ZIP от старой ветки Jellyfin 10: он несовместим с этой сборкой.

## Получение API-токена

Для запросов плагину нужен **собственный API-токен**. Общий встроенный токен не используется.

1. Откройте Telegram-бот [@poiskkinodev_bot](https://t.me/poiskkinodev_bot).
2. Получите в боте личный токен (бесплатный demo/free-тариф подходит).
3. Скопируйте токен: он передаётся в заголовке `X-API-KEY`.

**Дневной лимит.** У бесплатного токена ограничено число запросов в сутки (по данным API, 200: актуальное значение возвращает запрос `GET /v1.5/token`, он сам не расходует лимит). Счётчик сбрасывается в полночь по московскому времени. Поэтому плагин запрашивает минимум данных: карточка фильма или сериала занимает один запрос, сезоны сериала ещё один, остальное включается в настройках.

## Настройка плагина

1. В Jellyfin откройте **Панель управления → Плагины → Мои плагины → КиноПоиск → Настройки**.
2. Вставьте личный токен в поле API-токена и сохраните настройки.
3. Откройте **Панель управления → Медиатеки**.
4. Для каждой библиотеки с фильмами или сериалами нажмите **Изменить**.
5. В разделе **Загрузчики метаданных** включите флажок **КиноПоиск**. Проверьте настройки отдельно для библиотек фильмов и сериалов.
6. Сохраните изменения.

**Важно:** установка и настройка API-токена сами по себе не включают КиноПоиск как загрузчик метаданных. Если флажок **КиноПоиск** в настройках библиотеки выключен, Jellyfin не будет использовать этот источник при обычной загрузке метаданных.

### Дата премьеры

В настройках плагина можно выбрать, какая дата записывается в поле «Дата выхода» у фильмов и сериалов:

- **Мировая премьера** (по умолчанию); если её нет, берётся самая ранняя известная дата;
- **Российская премьера**: дата выхода в российский кинопрокат; если её нет, берётся мировая;
- **Только год выпуска**: датой считается 1 января года выпуска.

Повторные прокаты не учитываются. Даты входят в карточку фильма, поэтому ни один вариант не тратит дополнительных запросов. Если подходящей даты нет, берётся 1 января года выпуска.

### Дополнительные запросы

Эти настройки по умолчанию выключены, потому что каждая тратит дневной лимит:

- **Загружать трейлеры**: один дополнительный запрос на каждый фильм или сериал;
- **Загружать подробные данные персон** (дата и место рождения): один запрос на каждого человека. Фотографии актёров и съёмочной группы загружаются и без этого: они берутся из карточки фильма.

## Возможности

Плагин поддерживает:

- поиск и получение метаданных фильмов и сериалов;
- автоматическое сопоставление по названию, году выпуска и IMDb ID;
- загрузку рейтингов и описаний;
- получение постеров и фоновых изображений;
- сведения об актёрах и других персоналиях, а также изображения персон;
- ссылки на страницы КиноПоиска;
- получение трейлеров YouTube (включается в настройках).

### Поиск по ID КиноПоиска

При ручном поиске / идентификации фильма можно указывать числовой ID из URL КиноПоиска. Например:

- `687670`
- `kp-687670`
- `kp687670`

Для автоматического распознавания ID в имени файла или папки также используются префиксы `kp-` и `kp`.

Пример URL: `https://www.kinopoisk.ru/film/687670/`.

## Ограничения и примечания

- Для работы необходим доступ Jellyfin-сервера к `api.poiskkino.dev`.
- API-токен индивидуален для вашей учётной записи. Не публикуйте его в логах, скриншотах, issue или публичных конфигурациях.
- У бесплатного токена есть дневной лимит запросов. При его исчерпании плагин узнаёт время сброса от API (запрос `/v1.5/token` лимит не тратит), делает паузу до сброса и после него продолжает работу. Отказ записывается в журнал один раз.
- Для бесплатного demo/free-тарифа список (пагинация) доступен только до 10-й страницы. Плагину это не мешает: он запрашивает фильм по ID, поиск по названию (первая страница), сезоны и поиск по IMDb ID.
- Список актёров и съёмочной группы берётся из карточки фильма и у API короче, чем раньше (например, около 10 актёров у многих сериалов). Люди без фотографии, как и раньше, не добавляются. Актёры дубляжа в состав не входят.
- Роль актёра (имя персонажа) API в карточке фильма не передаёт; вместо неё указывается профессия.
- Для получения результатов КиноПоиск должен быть выбран в качестве загрузчика метаданных соответствующей библиотеки.

## Что изменено в форке

По сравнению с исходной линией плагина этот форк подготовлен для Jellyfin 12.4 и .NET 10. Основные изменения:

- обновлены целевые платформы и зависимости Jellyfin до линейки 12.4;
- плагин переведён с Kinopoisk Unofficial API на [poiskkino.dev API](https://poiskkino.dev/) v1.5; генерируемый клиент заменён небольшим клиентом с описанием только нужных полей;
- на фильм или сериал уходит один запрос вместо четырёх-пяти: состав, даты премьер и постер входят в карточку;
- квота определяется по ответу `/v1.5/token`, а не по фиксированному расписанию;
- исправлена регистрация metadata providers и image providers в DI-контейнере Jellyfin 12;
- добавлен прямой поиск фильма по числовому ID, а также форматам `kp-<id>` и `kp<id>`;
- удалён общий API-токен: каждый пользователь задаёт личный ключ;
- добавлены ограничения параллельных запросов проверки URL изображений, таймауты и корректная отмена;
- добавлены CI-сборка и тесты на реальных ответах API.

## Сборка из исходников

Требуется .NET 10 SDK.

```bash
dotnet restore ./src/Jellyfin.Plugin.Kinopoisk.sln
dotnet build --configuration Release ./src/Jellyfin.Plugin.Kinopoisk.sln
dotnet test --configuration Release ./src/Jellyfin.Plugin.Kinopoisk.sln
```

В релизный ZIP входят сборки плагина и API-клиента.

## Сообщения об ошибках

При создании issue укажите:

- версию Jellyfin Server;
- версию плагина;
- тип библиотеки (фильмы / сериалы);
- выполняемое действие и ожидаемый результат;
- релевантные фрагменты логов Jellyfin.

Перед публикацией логов удалите API-ключи, токены и другие приватные данные.
