# КиноПоиск Next — плагин метаданных для Jellyfin 12.4

Плагин добавляет **КиноПоиск** в качестве источника метаданных для фильмов и сериалов в Jellyfin. Он использует [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/) для получения информации о произведениях и персоналиях.

> Это отдельный форк, предназначенный для **Jellyfin 12.4**. Он не является официальным плагином Jellyfin или официальным продуктом КиноПоиска.

## Совместимость

- **Jellyfin Server:** 12.4.x (целевой ABI: 12.4.0.0). Плагин собирается против пакетов Jellyfin 12.4.0 и проверяется на этой версии сервера.
- **.NET:** 10.
- Версия плагина начинается с версии Jellyfin, для которой он собран: 12.4.x.y.
- Серверам Jellyfin 12.0–12.3 каталог по-прежнему предлагает последнюю сборку предыдущей линии (12.1.0.x); она больше не развивается.
- Сборки для Jellyfin 10.x этим форком не поддерживаются.

## Установка

### Через каталог плагинов (рекомендуется)

1. Откройте **Панель управления → Плагины → Репозитории**.
2. Добавьте репозиторий со следующим URL манифеста:

   ```
   https://raw.githubusercontent.com/Rev01T/jellyfin-plugin-kinopoisk-next/master/dist/manifest.json
   ```

3. Сохраните репозиторий и перейдите в **Плагины → Каталог**.
4. Найдите **КиноПоиск** и установите плагин.
5. Перезапустите Jellyfin, если сервер запросит это после установки.

### Ручная установка

1. Откройте раздел [Releases](https://github.com/Rev01T/jellyfin-plugin-kinopoisk-next/releases).
2. Скачайте ZIP-архив последнего релиза для Jellyfin 12.
3. Установите плагин способом, предусмотренным вашей установкой Jellyfin, и перезапустите сервер.

Не устанавливайте ZIP от старой ветки Jellyfin 10: он несовместим с этой сборкой.

## Получение API-ключа

Для запросов плагину нужен **собственный API-ключ**. Общий встроенный токен не используется.

1. Откройте [страницу профиля Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/profile).
2. Зарегистрируйтесь или войдите в свою учётную запись.
3. Найдите строку **API-KEY** в профиле и скопируйте значение.

Если вы не авторизованы, сервис перенаправит вас на главную страницу. После регистрации или входа снова откройте страницу профиля.

## Настройка плагина

1. В Jellyfin откройте **Панель управления → Плагины → Мои плагины → КиноПоиск → Настройки**.
2. Вставьте личный ключ в поле API-токена и сохраните настройки.
3. Откройте **Панель управления → Медиатеки**.
4. Для каждой библиотеки с фильмами или сериалами нажмите **Изменить**.
5. В разделе **Загрузчики метаданных** включите флажок **КиноПоиск**. Проверьте настройки отдельно для библиотек фильмов и сериалов.
6. Сохраните изменения.

**Важно:** установка и настройка API-ключа сами по себе не включают КиноПоиск как загрузчик метаданных. Если флажок **КиноПоиск** в настройках библиотеки выключен, Jellyfin не будет использовать этот источник при обычной загрузке метаданных.

### Дата премьеры

В настройках плагина можно выбрать, какая дата записывается в поле «Дата выхода» у фильмов и сериалов:

- **Мировая премьера** (по умолчанию);
- **Российская премьера**: сначала дата выхода в российский кинопрокат, затем DVD, цифровой релиз и Blu-ray; если российской даты нет, берётся мировая. Повторные прокаты не учитываются;
- **Только год выпуска**: без дополнительных запросов, датой считается 1 января года выпуска.

Первые два варианта тратят один дополнительный запрос к API на каждый фильм или сериал, что уменьшает остаток дневной квоты.

## Возможности

Плагин поддерживает:

- поиск и получение метаданных фильмов и сериалов;
- автоматическое сопоставление по названию, году выпуска и IMDb ID;
- загрузку рейтингов и описаний;
- получение постеров и фоновых изображений;
- сведения об актёрах и других персоналиях, а также изображения персон;
- ссылки на страницы КиноПоиска;
- получение трейлеров YouTube.

### Поиск по ID КиноПоиска

При ручном поиске / идентификации фильма можно указывать числовой ID из URL КиноПоиска. Например:

- `687670`
- `kp-687670`
- `kp687670`

Для автоматического распознавания ID в имени файла или папки также используются префиксы `kp-` и `kp`.

Пример URL: `https://www.kinopoisk.ru/film/687670/`.

## Ограничения и примечания

- Для работы необходим доступ Jellyfin-сервера к `kinopoiskapiunofficial.tech`.
- API-ключ индивидуален для вашей учётной записи. Не публикуйте его в логах, скриншотах, issue или публичных конфигурациях.
- У API могут быть собственные ограничения квоты и доступности. При исчерпании лимита плагин делает паузу перед следующими запросами.
- Для получения результатов КиноПоиск должен быть выбран в качестве загрузчика метаданных соответствующей библиотеки.

## Что изменено в форке

По сравнению с исходной линией плагина этот форк подготовлен для Jellyfin 12.4 и .NET 10. Основные изменения:

- обновлены целевые платформы и зависимости Jellyfin до линейки 12.4;
- устранена генерация NSwag API-клиента из сети во время сборки: сгенерированный клиент хранится в репозитории;
- исправлена регистрация metadata providers и image providers в DI-контейнере Jellyfin 12;
- добавлен прямой поиск фильма по числовому ID, а также форматам `kp-<id>` и `kp<id>`;
- удалён общий API-токен: каждый пользователь задаёт личный ключ;
- добавлены ограничения параллельных запросов проверки URL изображений, таймауты и корректная отмена;
- добавлена обработка ответа API 402 и пауза запросов при исчерпании квоты;
- добавлены CI-сборка и тесты для контроля изменений.

## Сборка из исходников

Требуется .NET 10 SDK.

```bash
dotnet restore ./src/Jellyfin.Plugin.Kinopoisk.sln
dotnet build --configuration Release ./src/Jellyfin.Plugin.Kinopoisk.sln
dotnet test --configuration Release ./src/Jellyfin.Plugin.Kinopoisk.sln
```

В релизный ZIP входят сборки плагина и API-клиента.

## Сообщения об ошибках

При создании issue укажите:

- версию Jellyfin Server;
- версию плагина;
- тип библиотеки (фильмы / сериалы);
- выполняемое действие и ожидаемый результат;
- релевантные фрагменты логов Jellyfin.

Перед публикацией логов удалите API-ключи, токены и другие приватные данные.
