# Changelog

## [12.4.2.0]

- Запросы к API теперь идут не чаще 4 в секунду. Лимит API: 5 в секунду (заголовок `x-ratelimit-limit`), прежняя пауза 110 мс его превышала, и на пачке запросов приходил ответ 429. При 429 без заголовка `Retry-After` клиент ждёт время из `x-ratelimit-reset`.
- Убрана настройка «Загружать трейлеры» и запрос трейлеров: API не отдаёт поле `videos` (проверено на бесплатном токене, пусто у всех проверенных фильмов). Трейлеры, которые давал прежний API, недоступны.
- В тестах появился записанный ответ 404 для несуществующего ID: `{"message":"По этому id ничего не найдено!"...}`.

## [12.4.1.0]

- Плагин переведён с Kinopoisk Unofficial API (kinopoiskapiunofficial.tech) на poiskkino.dev API v1.5 (`https://api.poiskkino.dev`). **Нужен новый токен**: его выдаёт Telegram-бот @poiskkinodev_bot. Старый ключ не подходит.
- Сгенерированный клиент NSwag и патчеры ответов удалены. Вместо них небольшой клиент с описанием только используемых полей. Нечитаемое поле пропускается и записывается в журнал, остальные данные не теряются.
- Один запрос вместо четырёх-пяти на фильм или сериал: состав, даты премьер и постер приходят в карточке `GET /v1.5/movie/{id}`. Запросы персонала, прокатов и трейлеров убраны.
- Квота: дневной лимит и время сброса берутся из `GET /v1.5/token` (он лимит не тратит). Расписание сброса «03:00 МСК» и код 402 больше не используются: при ответе 402, 403 или 429 клиент проверяет остаток запросов, и только при нуле делает паузу до времени сброса. Кратковременный 429 повторяется один раз.
- Дата премьеры берётся из карточки и больше не требует дополнительного запроса. «Российская премьера» теперь означает выход в российский кинопрокат (раньше учитывались и DVD, цифра, Blu-ray); если даты нет, берётся мировая, затем 1 января года выпуска.
- Новые настройки (по умолчанию выключены, потому что тратят дневной лимит): «Загружать трейлеры» (один запрос на тайтл) и «Загружать подробные данные персон» (один запрос на человека). Фото персон берутся из карточки фильма без запросов.
- Статус и дата окончания сериала определяются по годам выпуска (`releaseYears`): открытый диапазон означает, что сериал выходит.
- Состав: актёры дубляжа не добавляются; роль актёра API не отдаёт, вместо неё указывается профессия. Список в ответе API короче, чем у прежнего API.
- Ссылки на YouTube вида `/embed/` приводятся к `watch?v=`.
- Номер сезона и эпизодов берётся из ответа `GET /v1.5/season`; сезоны сортируются по номеру.
- Тесты на VCR-кассетах заменены тестами на реальных ответах API (`fixtures`).

## [12.4.0.2]

- Исправлено: рейтинг критиков записывался в 10 раз больше (670 вместо 67). `ratingRfCritics` в API уже в процентах и больше не умножается. `ratingFilmCritics` по-прежнему переводится из шкалы 0–10, но значения выше 10 считаются процентами. Значение ограничено 100.
- Исправлено: после исчерпания квоты плагин блокировал запросы ровно на час от первого отказа и повторял устаревший ответ API с числом запросов до сброса. Теперь пауза не длится дольше ближайшего ежедневного сброса (03:00 МСК), а в первые 15 минут после сброса повторные попытки идут раз в минуту. Устаревший ответ больше не повторяется, а сообщение в журнале указывает время сброса.
- Провайдеры сезонов и эпизодов больше не ломают обновление метаданных при ошибке API: сбой записывается в журнал, Jellyfin использует другие источники. Исчерпание квоты пишется в журнал один раз, а не для каждого элемента.
- Проверка изображений персон и постеров: общий лимит в 6 одновременных запросов на весь плагин (раньше 8 на каждый вызов) и кэш результатов (рабочие ссылки 24 часа, отсутствующие изображения 6 часов, сетевые сбои 1 минута). Ошибки сервера (5xx, 429) больше не считаются отсутствием изображения.
- Добавлены тесты рейтинга критиков, расписания сброса квоты, паузы после отказа, кэша и лимита проверки изображений и устойчивости провайдеров сезонов и эпизодов.

Прежние правила не менялись: пакеты `Jellyfin.*` обновляются только патчами, `Microsoft.*` без мажорных версий.
- Функциональных изменений плагина нет.

## [12.1.0.10]

- Точная дата премьеры из данных о прокате теперь заполняется и для фильмов, а не только для сериалов. Раньше у фильмов это всегда было 1 января года выпуска.
- В настройках плагина добавлен выбор даты премьеры: мировая (по умолчанию), российская (кино, затем DVD, цифра и Blu-ray, без повторных прокатов; запасной вариант мировая) или только год выпуска без дополнительных запросов.
- В журнал на уровне Debug пишется список найденных дат проката элемента, чтобы можно было проверить выбор.
- Добавлены тесты выбора даты премьеры.

## [12.1.0.9]

- Исправлено: у сериалов название, описание и остальные данные КиноПоиска не применялись, если ответ `/distributions` содержал `null` (например, в `subType`). Ошибка разбора выбрасывала весь результат провайдера.
- Разбор ответов API стал терпимым к `null`, отсутствующим полям и неизвестным значениям перечислений (`DistributionType`, `DistributionSubType`).
- Дополнительные запросы (состав, трейлеры, даты премьер, изображения персон) больше не отменяют основные метаданные: при сбое такого запроса в журнал пишется предупреждение, а название, описание и рейтинги сохраняются.
- Добавлены тесты разбора ответа `/distributions`.
